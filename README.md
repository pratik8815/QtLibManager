## 🚀 Overview

**QtLibManager** is a desktop-based Library Management System developed using **C++14, Qt5, Qt Widgets, and SQLite**. It provides a graphical interface for managing book records and library operations while demonstrating object-oriented programming, event-driven application design, and database integration.

## ⚙️ Getting Started

### Prerequisites

- Qt5 development environment
- Qt Creator IDE
- C++14-compatible compiler
- SQLite support for Qt

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/pratik8815/QtLibManager.git
```

**2. Open the project**

Open the `.pro` file or `CMakeLists.txt` in Qt Creator, depending on your project configuration.

**3. Configure the build**

Select a compatible Qt5 kit and compiler.

**4. Build and run**

Build the project and launch the application from Qt Creator.
